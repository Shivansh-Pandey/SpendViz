# SpendViz 💰

A beautiful subscription tracker that visualizes your monthly spending through interactive charts. Turn your subscriptions into stunning treemaps, swarm plots, and bubble charts.

## Features

- 📊 **Multiple Visualizations**: Switch between treemap grid, beeswarm, and bubble layouts
- 🎨 **100+ Preset Subscriptions**: Quick-add popular services with automatic pricing
- 🔍 **Smart Search & Filters**: Find subscriptions by category or search
- 💾 **Local Storage**: Your data stays private in your browser
- 📱 **Responsive Design**: Works great on desktop and mobile
- 🖼️ **Export**: Save your visualization as an image
- 💱 **Multi-Currency**: Supports 38+ currencies

## Quick Start

1. Clone or download this repository
2. Open a terminal in the project folder
3. Run: `npx serve . -l 3000`
4. Open http://localhost:3000 in your browser

No build process needed - it's pure HTML, CSS, and JavaScript!

## Usage

1. Click "Add first subscription" or select from popular services
2. Browse 100+ presets organized by category (Streaming, Gaming, AI, Productivity, etc.)
3. Add custom subscriptions with optional website for automatic icon fetching
4. Toggle between different visualization styles (Grid, Swarm, Bubbles)
5. Import subscriptions from bank statements (CSV)
6. Export your spending visual to share or save
